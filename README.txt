CF Tracker (installable offline app)

Files: index.html, manifest.json, sw.js, icon-180.png, icon-192.png, icon-512.png
Keep all files together in one folder.

HOST (needed once, must be HTTPS):
 Option A: Netlify Drop (app.netlify.com/drop). Drag this whole folder in. You get a link.
 Option B: GitHub Pages. Upload the files to a repo, then Settings > Pages.

INSTALL ON IPHONE:
 Open the link in Safari > Share > Add to Home Screen > Add.
 Open it once while online. After that it works offline.
